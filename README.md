# 我的子彈筆記

個人使用的網頁 App。手機底部可切換 Day、Week、Month、Year。各檢視共用同一份筆記資料，以台灣時間判定日期，週日為每週第一天。

## 開啟網頁 App

使用網站擁有者的 ChatGPT 帳號登入，即可跨裝置使用現有筆記。[開啟「我的子彈筆記」](https://my-bullet-notebook.workspace-926599.chatgpt.site)

## 發佈與更新

1. 在 ChatGPT Sites 開啟「我的子彈筆記」，使用原有專案。日後可直接在專案的工作對話提出變更。
2. 在原始碼目錄執行 `npm ci`，再執行 `npm run build`，確認產出 `dist/server/index.js`。Sites 部署還需要同一份原始碼中的 `.openai/hosting.json`；其中 `d1` 設為 `DB`。
3. 儲存新版本並發佈至原網站，維持僅擁有者存取。部署時會套用 `drizzle/` 的資料庫結構變更。
4. 手機使用擁有網站的 ChatGPT 帳號打開正式網址，新增一筆測試筆記。用同一帳號在電腦打開同一網址，重新整理後核對筆記。
5. 更新時使用既有網站和資料庫繫結。新的結構變更寫入下一份遷移檔，保留已套用的遷移。

Sites 提供登入並在伺服器端注入訪客 ID。資料庫查詢都使用這個 ID 識別筆記擁有者。網頁需要連線才能讀取及寫入資料。
